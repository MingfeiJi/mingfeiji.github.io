CONTENT CREATION · 详细 PRD

内容创作模块 · 详细 PRD

把「素材 + 意图」变成「成稿 / 成片」的批量创作工作台。不是单条编辑器，而是「选题 → 召回素材 → 生成 / 拼接 → 套模板 → 批量产出 → 送审 → 回流」的流水线——人定调、AI 起量。它上承资产库（素材与创作篮），下接审核与发布，并把表现回流成爆款配方反哺选题。

01

产品本质 & 核心闭环

一句话：用户带着【选题 / 脚本 / 一篮素材】进入，系统用【召回 + 生成 + 拼接 + 模板 + 批量】把它转成【可发布的图文 / 视频成片】，再通过【表现回流】沉淀成爆款配方反哺下一轮。

核心闭环：选题 / 脚本 → 召回素材 → 生成 / 拼接 → 套模板 → 批量产出 → 送审 → 表现回流（配方 / 选题）。角色与高频任务：编导（定选题 / 写脚本）· 剪辑（拼接成片 / 套模板）· 运营（批量产出 / 复刻爆款）。

06

AI 能力嵌入方式

AI 出草稿，人定稿

单条动作

  • 选题分析 · 脚本生成 / 改写 / 拆分镜
  • 召回拼接 · 文生图 · 图生视频 · 视频生视频
  • 字幕+脚本直出 · 生成相似变体

批量动作

  • 批量生成 N 条 · 批量套模板
  • 批量改写 / 换素材 · 批量送审 · 批量导出
  • 按爆款配方批量复刻
✦
原则：AI 出草稿、人定稿 · 每条结果可预览 / 可比较 / 可保存 / 可回滚（版本 + 血缘）· 批量生成必进任务队列、进度与成本 / 额度可见 · 成片表现回流、好的可一键标成爆款配方 · 与资产库（取素材）和审核台（送审）双向打通。

核心用户流

用户流关键步骤成功标准
脚本 → 成片贴脚本 → 召回素材 → 拼接草稿 → 字幕脚本直出 → 送审一条脚本直出一条成片
选题 → 批量 N 条选一个选题 → 批量生成 5 条图文 → 逐条微调 → 批量导出一次产出一批、可逐条调
创作篮 → 图文批量资产库带入篮 → 进图文创作 → AI 排版 → 批量出素材篮直接成一批图文
素材 → 视频变体选视频 → 视频生视频 → 多变体 → 差异校验 → 入库 / 用变体差异达标可用
成片 → 送审 →（发布）成片 → 送审核台 → AI 初筛 → 人终审 →（发布暂不做）终审通过进发布队列
副驾代办「做 5 条火车短途图文」→ 自动编排 选题/召回 → 生成 → 排版 → 送审 → 人收口一句话起一批、人审收口
09

状态 / 异常 & 性能成本

生成任务状态机：排队 → 生成中 → 完成 / 失败（可重试），批量进度逐条可见。草稿：带版本与血缘（改自哪条、用了哪些素材），可回退。审核衔接：送审后回显 AI 初筛结果（通过 / 驳回原因），驳回可返修。同质化：批量产出之间做差异度校验，过雷同提示再改。成本：批量优先、生成结果缓存、按项目显示额度与成本、可设上限。

MVP / P1 / P2

P0 · MVP（跑通图文批量）

  • 批量创作流（图文优先）+ 草稿逐条编辑
  • 脚本生成 / 改写 · 召回拼接
  • 文生图 / 基础生成 · 批量生成 / 导出
  • 选中即用 AI 动作 · 生成任务队列

P1 / P2

  • P1：视频生成 / 视频生视频 · 模板套用 · 字幕+脚本直出剪辑 · 选题推荐 · 审核衔接 · 版本血缘
  • P2：爆款配方复刻 · 智能推荐 · Agent 批量代办 · 多渠道适配
  • 暂不做：养号 / 发布（成片止于"通过 + 导出 / 进队列"）
