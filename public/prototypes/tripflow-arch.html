FLAGSHIP CASE · 业务流程 × AI 原子能力（脱敏）

内容增长营销中台 · 业务流程详解

头部 OTA 出海出行业务线 · AI 产品经理 · 0-1 主导。重点不在编排多复杂，而在把 70–80 人内容团队的生产流程组织清楚、在每个关键节点嵌入对的 AI 能力；并基于 LobeHub 落地多 Agent + Skill + MCP + 知识库打通。我的核心价值在于内容增长业务里的 AI 需求调研 → 落地方案 → 推动落地。

核心判断（需求调研的产物）

把一线《AI 使用反馈》归类后，根因高度一致：问题不在"缺数据"，在"缺判断"——工具在用 AI 搬运内容，但用户的时间仍花在"自己判断有没有用、为什么火"上。所以方向不是再多接数据源，而是把价值从「采集」上移到「判断与产出」。

分工边界 · 开发管「数据进出 + 确定性计算」，Dify 管「一切文本理解与生成」。
产品自闭环 · AI 工作流的搭建 / 提示词调优 / 效果迭代由我独立完成，不占开发排期。

▸ 真实落地：数据 → AI → 应用 全链路 以灵感引擎模块为例
L1 采集层TikHub / 平台接口开发 · 硬逻辑
接口调度、翻页游标、限频重试、CDN 下载转码——AI 不直接碰原始 API 响应。
L2 存储层开发
爆款内容表 + 评论/账号快照/词库/选题池/报告表；结构化字段落库。
L3 计算收敛层开发 · 硬逻辑
两层过滤 + simhash 去重；分平台互动率公式、时间衰减、热度分、关联度三路融合；精选引擎（订阅×阈值×多样性 → 今日灵感 Top12）。
L4 AI 层Dify Workflow API产品自闭环
~10 个原子工作流：入池打标 / 爆款归因 / 可挂载性评分 / 仿写脚本 / 节点状态 / 全局洞察 / 博主摘要 / 周报 / 扩词 / 链接拆解串联；Dify 知识库做语义召回。输出全部为 JSON 回写库，提示词可热更、不影响系统稳定。
L5 应用层前端
今日灵感 / 热点雷达 / 选题池 / 竞品监控 / 报告中心 / 关键词库；前端只读库不读 Dify。

▸ 基于 LobeHub 落地的多 Agent Skill + MCP + 知识库打通，已嵌入业务产生效用

落地了什么（不止设想）

  • 以 LobeHub 零迁移承载 Agentic 编排：主 Agent 做意图识别与分发，下挂业务域 SubAgent 协作
  • 每个 Agent 统一封装为 Skill（PE + 业务规则）；Skill 调 MCP / Tool 接入企业知识库，形成"识别 → 调用 → 语义召回 → 回复"的调用闭环
  • MCP 薄包装：70% 复用既有接口、30% 新建，总 Tool 数 < 20 覆盖全业务域
  • 知识库挂载产线知识（卖点 / 功能点 / FAQ）做语义召回

有效的业务效用

  • 多 Agent + Skill 把灵感、创作、审核等环节真正接进生产流程，不是孤立 demo
  • Skill / MCP / 知识库打通后，产品侧可独立增删 Agent、热更提示词，不占开发排期 → 迭代周期以天计
  • 完整五层 Multi-Agent（6 阶段意图 Pipeline + 组合意图 + Entity Stack + 6 业务域）作为指导演进的架构蓝图，在 LobeHub 上分阶段坐实
▸ 我的角色：需求调研 → 落地方案 → 推动 + 团队管理

从诊断到落地的全链路推动

  • 需求调研：3 小时/人多层级深访 +「需求四象限 / 伪需求过滤」，从 7 环节锁定 2 个 P0、毙掉「全 AI 一键出片」「自动养号」2 个伪需求；诊断出"缺判断不缺数据"
  • 落地方案：三层重构（数据接入 / AI 洞察 / 产出应用）、数据→AI→应用全链路设计、分部门实现拆解、Prompt 规范与上线预估
  • 推动：定分工边界让产品 AI 工作流不占开发排期；四层转型组织 + 蓝图签字 +「业务归运营、技术归工程」飞轮分工，把一次性项目改造成可持续机制

团队管理与成果

  • 统筹 3 UI + 5 名以上开发；带教 3 实习生 + 1 正岗产品，"人人用 Agent"
  • 驻场一线调研，向直属 / 集团 CIO 双周、向亚洲区总经理英文汇报
  • 已实测（MVP）：单周生成素材 500 条（采纳 40%）/ 发布 990 条 / 播放 100 万+；目标全年省 ¥500 万 / 2.8 万工时 ≈ 13 FTE
  • 组织影响力：从单团队提效项目，升级为推动事业群（BG）级 AI 化转型立项的标杆案例
脱敏说明：公司、品牌、业务线名称均以行业 + 体量匿名化；流程与 AI 节点取自项目真实需求与落地文档，"已实测"与"目标"严格区分、未夸大。
能力主张：在内容增长业务里把流程组织清楚、在对的节点嵌入对的 AI 能力，用产品自闭环的 Dify 工作流独立落地并持续迭代——这是 AI 需求调研、落地方案与推动能力的完整体现。
