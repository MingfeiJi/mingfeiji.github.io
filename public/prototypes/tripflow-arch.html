▸ 不只是产品，是组织转型 + 团队管理

转型即组织设计（关键判断）

  • 3 小时/人多层级深访 +"需求四象限 / 伪需求过滤"，从 7 环节锁定 2 个 P0、毙掉「全 AI 一键出片」「自动养号」2 个伪需求，避免千万级研发错配
  • 核心判断：本质是"运营侧 AI 化转型"而非单一产品
  • 建四层转型组织（指委会 / 运营合伙人 / 域专家 / 种子用户）+ 业务蓝图签字机制
  • 飞轮分工：业务变化（Skill + 数据）归运营、技术稳定（代码）归工程——把一次性项目改造成可持续机制

团队带教与汇报

  • 统筹 3 名 UI + 5 名以上开发的跨职能协作
  • 带教 3 名实习生 + 1 名正岗产品，以"人人用 Agent"方式提升交付效率
  • 驻场业务一线做场景调研，同时向直属 / 集团 CIO 双周汇报、向亚洲区总经理英文汇报
  • 输出《Agent 实施手册》《MCP / Skill 规范》等可移交工程资产
