## 页面呈现

- 将来源、概念、方法、项目、作品、反馈组成可点击的个人本体结构图；选中对象后显示定义、字段与关系。
- 这是基于真实库职责与来源规则的说明性结构模型，不是对全库自动抽取后的实体图，也未创建 RDF/OWL 本体数据库。
- Grokbot 展示为用户指定的对话与任务入口；Codex 负责执行和校验；Obsidian 承接长期知识，独立 RSI 承接个人复盘。
- 协作循环：捕获问题 → 找回上下文 → 执行生成 → 校验确认 → 回写复盘，再回到下一轮问题。
- 本机 Codex 配置中资料采集与 RSI 日批为 ACTIVE；页面仅写“已配置”，不据配置推断近期运行成功。Grokbot 到本地库的自动接续尚未技术验证，写为持续完善。
- 五类资料与独立 RSI 分层展示；私人正文不复制进仓库或公开图谱。
- 原 192 节点、361 关联的公开文章图谱保留，明确为公开选集。既有藏书阁与公开 PDF 入口保留，去除旧知识区无法核实的“全部精读”等表述。
- 本体互动仅使用少量原生 JS 和 SVG/CSS，不引入新依赖、外部 API 或常驻动画。
