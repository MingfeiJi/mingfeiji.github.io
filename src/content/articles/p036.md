# PE四象限：用AI的正确姿势

> 90%的人用AI效率低，不是AI不行，是不会提问。今天分享一个大厂AI产品经理都在用的方法论——PE四象限。

---

## 为什么很多人用AI感觉"不好使"？

我经常听到这样的抱怨：
- "AI回答的都是废话"
- "它根本不懂我要什么"
- "还不如自己搜索来得快"

问题出在哪？

**不是AI不行，是你没找到正确的提问方式。**

用AI就像跟一个能力很强但不了解你的同事协作。你的指令越模糊，它的输出越离谱；你的指令越精准，它的产出越惊艳。

今天分享的PE四象限方法论，就是帮你找到正确提问方式的框架。

---

## PE四象限是什么？

PE是"Prompt Engineering"的缩写，但这个方法论的核心不是教你写复杂的提示词，而是帮你判断：**在什么场景下，应该用什么方式跟AI协作**。

四个象限按两个维度划分：
- **我是否知道这个信息**
- **AI是否知道这个信息**

形成四种场景：

| | AI知道 | AI不知道 |
|---|---|---|
| **我知道** | 第一象限：助理场景 | 第四象限：样本学习场景 |
| **我不知道** | 第二象限：学习场景 | 第三象限：共创场景 |

每种场景有完全不同的提问策略。

---

## 第一象限：你知道的AI也知道

### 场景特征

这是最常见的场景：**你知道怎么做，只是懒得做**。

典型任务：
- 改文档格式
- 写周报、会议纪要
- 数据整理、转换
- 翻译、校对

### 提问策略：直接下指令

这个场景不需要复杂的提示词技巧，关键是**指令要具体**。

**❌ 错误示范**
```
帮我整理一下会议内容
```

**✅ 正确示范**
```
把以下会议记录按"讨论议题-结论-待办"三个维度整理成表格。
待办需要标注责任人和截止日期。
如果原文没有明确责任人，标注"待确认"。
```

**核心原则**：
1. 明确输入格式
2. 明确输出格式
3. 明确边界情况的处理方式

---

## 第二象限：你不知道但AI知道

### 场景特征

你想学习新知识，AI是你的老师。

典型任务：
- 学习新概念
- 了解行业知识
- 获取专业建议

### 提问策略：三步追问法

很多人在这个场景下只会问一个问题就完了。

错。

学习场景的关键是**追问**，直到真正理解。

**第一步：要求标注出处**
```
请解释RAG技术的原理，并标注这个知识的主要来源。
```

**第二步：要求通俗化**
```
用通俗的语言重新解释一遍，最好能举一个生活中的例子。
```

**第三步：结合场景**
```
假设我是一个做客服系统的产品经理，给我3个RAG可以解决的具体业务场景。
```

**核心原则**：
1. 不要满足于第一个答案
2. 要求它用你能理解的方式解释
3. 要求结合你的真实场景

---

## 第三象限：你俩都不知道

### 场景特征

这是最难的场景：**探索未知领域，没有标准答案**。

典型任务：
- 头脑风暴
- 创意发散
- 探索新方向
- 解决开放性问题

### 提问策略：双散模型

这个场景下，不要期待AI一次给你完美答案。

**双散模型的核心**：AI负责发散，你负责收敛定方向，然后再迭代。

**第一轮：让AI发散**
```
给我10个关于"AI+教育"的创业方向，越多元越好，不要自我审查。
```

**第二轮：你来收敛**
```
从上面的方向中，我觉得第3、5、7比较有潜力。
请针对这三个方向，各给出3个具体的产品形态。
```

**第三轮：继续迭代**
```
方向5的第二个产品很有意思，帮我深入展开，包括：
- 目标用户是谁
- 核心功能有哪些
- 和竞品的差异化是什么
```

**核心原则**：
1. 先发散再收敛
2. 你做方向判断，AI做内容填充
3. 多轮迭代，逐步聚焦

---

## 第四象限：你知道但AI不知道

### 场景特征

你有特定的风格、标准、知识，但AI不知道。

典型任务：
- 让AI学习你的写作风格
- 处理小众/专业领域的内容
- 适配特定格式要求

### 提问策略：样本学习法（RCL）

这个场景下，**给例子比写规则更有效**。

**步骤一：提供样本**
```
以下是3个我满意的文案示例：

示例1：[内容]
示例2：[内容]
示例3：[内容]
```

**步骤二：让AI分析规则**
```
请分析这3个示例的共同特点，包括：
- 语气风格
- 结构特征
- 常用句式
```

**步骤三：生成新内容**
```
按照上述风格，帮我写一篇关于"AI产品经理转型"的文案。
```

**为什么有效？**

大模型有强大的泛化能力。给3-5个例子，它就能学会你的风格。这比写长长的规则描述更直观、更准确。

---

## 快速判断用哪个象限

| 你的情况 | 象限 | 策略 |
|------|------|------|
| 我知道怎么做，只是懒得做 | 第一象限 | 直接下指令 |
| 我想学习新东西 | 第二象限 | 三步追问法 |
| 我在探索，没有明确方向 | 第三象限 | 双散模型 |
| AI不懂我的风格/领域 | 第四象限 | 样本学习法 |

---

## 最后

很多人觉得"提示词工程"是玄学，其实不是。

核心就是两点：
1. **判断场景**：你和AI各自知道什么，不知道什么
2. **选择策略**：用对应的方式提问

PE四象限就是帮你做好这两步的框架。

**记住：不会提问不是AI的问题，是你没选对场景和方法。**
